# Dataset

## Overview

This folder contains the datasets used for the **Women's Clothing E-Commerce Customer Review Analysis** project.

The dataset comprises customer reviews submitted for women's clothing products sold through an e-commerce platform. It serves as the primary data source for analyzing customer satisfaction, recommendation behavior, and product performance.

---

## Dataset Information

| Attribute | Details |
|-----------|---------|
| Dataset Size | 23,486 customer reviews |
| Data Type | Structured tabular data |
| Unit of Analysis | One row represents one customer review |
| File Format | Microsoft Excel (.csv) |

---

## Folder Contents

| File | Description |
|------|-------------|
| **Women Clothing E-Commerce Review.csv** | Original dataset provided for the analysis. |
| **Women Clothing E-Commerce Review - Cleaned.csv** | Cleaned dataset used for exploratory analysis and dashboard development. |
| **Data Dictionary.md** | Description of each dataset field and its meaning. |

---

## Dataset Fields

| Field | Description |
|--------|-------------|
| Review ID | Unique identifier for each customer review |
| Clothing ID | Unique identifier for the clothing product |
| Age | Customer age |
| Title | Title of the customer review |
| Review Text | Full customer review |
| Rating | Product rating on a scale of 1 (lowest) to 5 (highest) |
| Recommended IND | Indicates whether the customer recommends the product (1 = Yes, 0 = No) |
| Positive Feedback Count | Number of customers who found the review helpful |
| Division Name | High-level product division |
| Department Name | Product department |
| Class Name | Product class |

---

## Notes
