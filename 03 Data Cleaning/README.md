# Data Cleaning

## Overview

This folder documents the data cleaning and preparation process performed before exploratory data analysis and dashboard development.

The objective was to ensure the dataset was accurate, consistent, and analysis-ready while preserving the integrity of the original data.

---

## Cleaning Objectives

The data cleaning process focused on:

- Identifying and handling missing values.
- Removing unnecessary columns.
- Verifying data types.
- Checking for duplicate records.
- Standardizing text fields.
- Creating calculated fields to support analysis.

---

## Deliverables

This folder contains:

| File | Description |
|------|-------------|
| **Data Cleaning Report.md** | Detailed documentation of all data quality issues identified and the actions taken to prepare the dataset for analysis. |

---

## Tools Used

- **Power Query (Power BI)** – Data cleaning and transformation
- **Microsoft Excel** – Initial data review and validation

---

## Outcome

The cleaned dataset was used as the foundation for all exploratory analysis, business insights, visualizations, and dashboard development presented in this project.
